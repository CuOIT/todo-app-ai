# Todo App AI

Ứng dụng Todo danh sách công việc tích hợp hỗ trợ AI.

## Mô tả

Dự án này sẽ phát triển một ứng dụng quản lý công việc (todo list) có tích hợp AI.

## Tính năng dự kiến

- Tạo, sửa, xóa và đánh dấu hoàn thành công việc
- Tích hợp AI: gợi ý ưu tiên, phân loại và nhắc nhở công việc
